# 次世代D39試験の結果CSV・欠測レース表示

`http://127.0.0.1:8767/next` の「結果明細CSV」「成績・収支CSV」から、選択した試験モデルの記録をダウンロードできる。

- 「改善前47項目」と「前走タイム接続版」は別フォルダー・別CSV。比較用の既存D39系も含む。Hの結果・成績は含めない。
- 明細はモデル×馬の行。開催日、レース、馬名、モデルID、保存時刻、予測順位・勝率、公式着順・単勝100円払戻、仮想購入・損益、確定/保留状態、出所を保持する。
- 集計は保存済み評価JSONのレースLL・Brier・AUC・本命着順率・仮想収支をそのまま使用する。CSV作成のための学習・閾値調整・追加の結果取得は行わない。
- 明細は各モデルの保存済み行、予測性能の比較表は比較対象モデルが全て揃った共通レース集合である。両者の件数は一致しない場合がある。`common_probability_cohort`・`common_financial_cohort` 列で対象を区別する。
- 文字コードはUTF-8 BOM付き。未確定の着順・払戻・損益は空欄。確定した不的中の払戻0円とは区別する。文字列セルにはExcelの数式解釈防止を適用する。
- スキーマは分析用の `keiba-lab.next-results.v1`。既存KEIBA LAB向け25列の後ろに状態・仮想収支・対象集合の列を追加している。

## 欠測レースの表示

正式T−10予想・答え合わせは全36対象レースを表示する。試験モデルが未保存でも、ほかのモデルに保存済みの正式予想・承認済みD39結果があれば表示する。本モデルの欠測を他モデルや参考予想で置換しない。

起動前に締切通過、元入力不足、保存期限超過などの理由を表示し、「本モデルの正式予想がないレースだけ」で絞り込める。結果未到着の場合も既知の出走馬を表示し、着順は未確定とする。Hは予想表示のみ。

全対象の表示用行は評価用の保存予想・結果JSONから分離しており、評価母数・CSVの行数・既存成績は変わらない。CSV明細には正式保存済みの予想だけを出力する。
