| ファイル | 内容 |

| report.md / summary.json | 月次件数、元の全対象を母数とする発表履歴対応率、AI/1番人気の購入数、未精算数、共通条件比較 |

**既定コマンドはHRを取得せず、払戻金額も自動認定しません。** 公式払戻入力がない購入は未精算、払戻・純利益・回収率は未算出です。AIと1番人気の選択・購入数は先に比較できます。実購入・約定ではなく、10分前の表示オッズで実際の払戻が保証されるわけでもありません。

本人が確認済みの公式単勝100円払戻ファイルを用意できたら、同じコマンドに `--payouts` を追加します。

```powershell
& 'C:\Users\acbd5\AppData\Local\JraRacingAI\venv\Scripts\python.exe' -B '.\scripts\run_v02_publication.py' --payouts 'C:\Users\acbd5\AppData\Local\JraRacingAI\ml-v02\inputs\payouts.json'
```

ファイル形式は [Version 0.2の確定公式払戻の入力](version_0_2.md#確定公式払戻の入力)を参照。通常最終版・全的中対象・100円基準・公式公表額を確認したレースだけを精算します。同着は対象ごとの公式額、プラス10も公表額を直接使い、最終オッズから金額を作りません。返還・特払・不成立・発売なし・訂正削除等の未解決は該当レースを保留し、確認済みの通常レースを止めません。

収益比較は同時点の価格と同じ正常精算条件を満たす共通集合で行います。AI購入レースに限定した比較も別掲します。購入0件のROIは未算出、未精算を含む月の総利益も未算出です。実精算結果から1番人気のROIを計算し、固定値にはしません。

保存済み入力を使う再計算は、既存の `simulate --policy <今回のpolicy.json> --predictions <元の予測フォルダー> --schedules <input-schedules.json> --odds <input-odds.json> --payouts <確認済み公式ファイル>` でDB接続なしに行えます。パスはすべて上記のOneDrive外領域内とします。元の入力・台帳は上書きしません。
