# 目的関数の有限比較（承認済み最大4fit）

2026-10-22承認の固定計画を使い、二値対照・4クラス分類・着順相対値回帰・LambdaRankを各1回比較します。
既存H・Stage 7・朝7時タスクを変更せず、DB接続・新規依存導入も行いません。

学習は2022-01-01〜2024-08-31、早期終了は2024-09-08〜10-31、較正は2024-11-08〜12-24。
評価は既存の2025年1〜9月の共通2,169レース・29,879頭です。探索に使用済みの開発評価です。
旧H・市場・旧ABCDは参考比較であり、同条件の主比較は新たな二値対照です。

特徴量生成済みキャッシュの39列、順序、カテゴリ辞書、7日遅延契約を再利用します。
着順・実出走頭数は目的変数作成専用として完全キー結合し、モデルへの入力列には含めません。
任意特徴量欠損による行の除外はありません。全出走馬・単一勝馬の対応が崩れれば学習前に停止します。

4クラスのラベルは1着=3、2〜3着=2、4〜5着=1、その他=0。
回帰は `(実出走頭数−着順)/(実出走頭数−1)`、LambdaRankは同じ0〜3関連度と完全レース群を使います。
二値・多クラスは既存のべき乗温度正規化、回帰・ランキングは安定Softmaxを使います。
温度は計画の有限グリッドから較正期間のレースLog Lossだけで決め、評価データを開く前にモデルへ保存します。
保存再読込みで較正後確率の一致を確認します。

上限は4fit、各300ラウンド（多クラス4木/round）、early stopping=20、CPU4スレッド。
失敗も1fitに数え、同じ構成の再試行や追加探索は行いません。
データ準備300秒、各学習ワーカー600秒、学習合計1,800秒、全ジョブ2,700秒。
親・ワーカー配下の全プロセス（Windows venvの実インタープリターを含む）のprivate commit合計を監視し12GiB超でプロセスツリーを停止します。
実行許可ごとの排他マーカーとfit開始・入場マーカーを保存し、同じ承認から学習枠を再発行しません。

成果物はすべて `%LOCALAPPDATA%\JraRacingAI\objective-pilot\evaluations\<ID>` に新規保存します。
`*.local.csv` は個別データを含むため共有しません。
`development_report.md/html/json` は匿名集計、`candidate_frozen.json` は有限比較の凍結記録です。
`preservation.json` は既存232ファイル・保護モデル・計画・タスク構成の保持確認です。
`completion.json` は消費したfit枠・所要時間・完了状態を記録します。
元の承認計画ファイルは変更しません。承認後の実行記録は新規フォルダーのauthorization.jsonです。
